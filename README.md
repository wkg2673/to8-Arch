# My Custom Arch-based OS

Welcome to my custom Arch-based `to8-Arch` distro!

I'm trying to create my own personalized Linux OS, based on Arch Linux and built upon the foundations of Archcraft.

**Status: In Development**

The distribution is currently under development. Features, packages, configurations, and overall design are subject to change.

More information and documentation will be added as development progresses.
